# Password Strength Checker

A beginner cybersecurity project built with Python.

## Features
- Detects weak, medium, and strong passwords
- Checks:
  - Length
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Special characters
- Gives security suggestions for weak passwords

## Technologies Used
- Python
- Regular Expressions (re)
